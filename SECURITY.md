# Security policy

## Reporting a vulnerability

Report a vulnerability privately with a GitHub draft advisory:

<https://github.com/smusali/echoChain/security/advisories/new>

Do not open a public issue for a security report.

## Supported versions

Security fixes go to the latest release on the default branch.

## Data sent to model providers

echoChain sends prompt text to third-party model providers. The usage guide describes what is stored and how to restrict provider routing:

<https://github.com/smusali/echoChain/blob/main/docs/USAGE.md>
